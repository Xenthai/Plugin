## 3. Quién lo ejecuta y cuánta capacidad hay

necesita su propio archivo: un producto se agota, un servicio se satura.

| Servicio | Quién lo puede ejecutar | Cuántos a la vez | Dónde se ve el calendario |

| — pendiente — | | | |

La segunda columna se cruza con [PEOPLE.md](PEOPLE.md): si sólo una persona puede ejecutar un
servicio que se vende seguido, eso es un **único punto de falla comercial**, no sólo operativo.
