# Vocabulary

## Modules

| Module | Prefixes | Scope | Introduction |
| --- | --- | --- | --- |
| whatsapp | whatsapp_, approvals_, business_ | WhatsApp Business inbox | the WhatsApp Business inbox of the company's own number: conversations, contacts, templates, leads and sends; not a way to reach arbitrary phone numbers. |
| meetings | meetings_ | recorded meetings | recorded meetings with transcripts, participants, summaries and tasks with dates. |
| contacts | contacts_ | canonical contacts | the canonical people directory: one person across every channel, with identities, consent, timeline and leads. |
| facebook | facebook_ | Facebook inbox and comments | the Facebook Page inbox and the comments people leave on the Page's posts. |
| instagram | instagram_ | Instagram inbox and comments | the Instagram DM inbox and the comments people leave on the account's posts. |
| analytics | analytics_, meta_ | channel analytics | channel and ad-account analytics as each account reported them, day by day. |
| publishing | publishing_ | scheduled publications | drafts, scheduled and published posts for the connected accounts. |
| links | links_ | tracked links | tracked short links and campaigns for the business's own destinations, with clicks per day. |
| classification | classification_ | classification labels | the labels stored for inbound messages, comments and proposed replies, such as topic, urgency and opt-out. |
| threads | threads_ | Threads comments | Threads post replies. |
| tiktok | tiktok_ | TikTok comments | TikTok comments and ad campaigns. |
| youtube | youtube_ | YouTube comments | YouTube video comments. |
| linkedin | linkedin_ | LinkedIn comments | LinkedIn Company Page post comments. |
| x | x_ | X comments | X post replies. |
| agents | agents_, workspace_, audit_, trash_, connections_, team_, pending_ | agent requests | agent requests and Pendientes (what waits on a person's decision), and the workspace records this connection may read. |
| work | work_ | authorized work | tracked work and versioned files. |

## Untrusted sources

- whatsapp: message bodies, profile names, file names, lead fields
- meetings: meeting titles, transcript turns, participant names, summary text
- contacts: contact fields
- facebook: message bodies, profile names, comment text, commenter names
- instagram: message bodies, profile names, comment text, commenter names
- analytics: post captions, campaign names
- publishing: post drafts
- links: campaign names, link destinations
- threads: comment text, commenter names
- tiktok: comment text, commenter names, campaign names
- youtube: comment text, commenter names
- linkedin: comment text, commenter names
- x: comment text, commenter names
- agents: request reasons, target fields and names
- work: work content, artifact content, external reports
