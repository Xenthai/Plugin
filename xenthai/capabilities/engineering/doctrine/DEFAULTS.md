# Defaults when free to choose

Implements: fuera del playbook (X9)

The repo's existing stack always wins. These apply to a new repo, a new package with no sibling,
or a question of "what would you pick". Every version is verified against the registry before use.

## TypeScript stack

| Concern | Default | Note |
|---|---|---|
| Language | TypeScript, strict, latest stable major verified | Zero errors is the bar |
| Runtime | Latest LTS Node; pinned in `.nvmrc` and `engines` | |
| Package manager | pnpm with catalogs in strict mode | The only lockfile; corepack-pinned |
| Build orchestrator | Turborepo with boundary tags per package | A cache hit is not freshness |
| Lint and format | Biome only | Never propose ESLint or Prettier plugins beside it |
| Git hooks | Lefthook with flat `run:` lines plus a secret scanner | Never bypass |
| Validation | Zod, latest major | Never class-validator |
| Unit and integration tests | Vitest | Real-database and HTTP levels where practices.md says so |
| Browser tests | Playwright | By hand or in CI per repo |
| UI primitives | shadcn/ui on Tailwind, as a `ui` package | Brand sites may hand-write CSS from tokens instead |
| Server-rendered web | Astro with islands | |
| App framework | Next.js when a React app needs it | |
| Backend | Serverless workers with a SQL store and object storage for event-driven products; a modular Node framework with PostgreSQL and a queue for transactional systems | Pick by workload, record the decision |
| Charts | The UI library's chart primitive | No second charting stack |
| Commits | Conventional Commits | |
| Diagrams | Mermaid | |
| Scripts | The runtime's native loader; no extra transpiler | |
| Fonts | Self-hosted, generated by a script with a drift test | |

## Other languages

Same doctrine; idiomatic tooling. Versions verified against each ecosystem's registry.

| Language | Package and env | Lint and format | Validation | Tests |
|---|---|---|---|---|
| Python | uv, `pyproject.toml` | ruff | pydantic | pytest |
| Go | modules | golangci-lint, gofmt | typed structs with explicit validation | `go test` with table tests |
| Rust | cargo | clippy, rustfmt | serde with typed newtypes | `cargo test` |
| Swift | SwiftPM | swift-format | Codable with explicit decoding | XCTest |

## Stance

1. Minimal provider surface: one billing ledger, one credential surface, one abstraction per capability.
2. Latest stable, verified: never the version training data remembers.
3. Native capability over a fallback; the chosen tool over the displaced one.
4. A new package gets its own config, its own boundary tag, and the shared config base.

## Before you finish

- The repo's stack was detected first; defaults used only where it had none.
- Every version came from the registry or the lockfile.
- The choice is recorded where decisions live.
