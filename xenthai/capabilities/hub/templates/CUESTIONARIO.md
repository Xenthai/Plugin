## Cómo llenarlo

Cada hub tiene dos partes: una tabla de datos generales y las preguntas de cada página propuesta. Se responde debajo de cada pregunta, con frases cortas y como se le explicaría a alguien que entra mañana.

- **No se sabe la respuesta:** se deja `[por confirmar]` y el nombre de quién la sabe.
- **Ya existe un documento:** se pega la liga.
- **No aplica:** se escribe "No aplica".
- **Una página sobra o falta:** se dice en un comentario.
- **Ejemplos:** se describe el caso sin datos reales de clientes.

Nunca se escribe en este documento, aunque sea interno:

- Datos personales o de clientes.
- Credenciales, contraseñas, llaves o números de cuenta.
- Cifras financieras internas o de inversionistas.
- Detalles de infraestructura o de seguridad.

Si una respuesta necesita algo de esto, se escribe "se comparte en persona con el responsable" y se sigue.

## Entrega y siguientes pasos

Un hub está listo para construirse cuando cumple estos cuatro puntos:

- [ ] Tiene responsable asignado en la tabla del inicio.
- [ ] Cada pregunta tiene respuesta, "No aplica" o `[por confirmar]` con el nombre de quién la sabe.
- [ ] Los documentos existentes están ligados.
- [ ] El responsable leyó las respuestas de su hub.

Cómo se construye cada hub:

1. {Coordinador} cambia el estado del hub a "En revisión" y avisa.
2. Se arma un borrador con el diseño de los hubs actuales y se marca lo que falta.
3. El responsable revisa el borrador y corrige.
4. Se publica, se comparte con quien corresponda y se agrega al selector de hubs.
