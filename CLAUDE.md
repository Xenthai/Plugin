# Convenciones de Git

- Commits en formato [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`, etc., describiendo qué cambia.
- Ramas en conventional branching acorde a la tarea: `feat/<descripcion>`, `fix/<descripcion>`, `chore/<descripcion>`, `docs/<descripcion>`, etc.
